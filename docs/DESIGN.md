# DESIGN.md — Hướng dẫn thiết kế

## Nguồn thiết kế

File thiết kế UI/UX (Figma export, mockup, hệ thống thiết kế) được quản lý tại thư mục [design/](../design/), trong cùng repo.

## Nguyên tắc

- Đồng bộ giữa Figma và code: khi thiết kế thay đổi, cập nhật lại file này để phản ánh design system mới nhất (màu sắc, spacing, component chuẩn...).

> Cập nhật link Figma và design system chi tiết khi có.
